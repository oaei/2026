Results for OAEI 2026 - Anatomy track

Experimental setting

We conducted experiments by executing each system in its standard setting and we compare precision, F-measure, recall and recall+. The measure recall+ indicates the amount of detected non-trivial correspondences. The matched entities in a non-trivial correspondence do not have the same normalized label.

For CHARM, DRAMA, LogMapLLM, LogMapBioLLM, and Mosaic, the authors submitted the alignments directly, so we do not report runtimes for these systems. (Their runtimes would in any case vary with the duration of LLM API calls.) We ran ALIN with 12GB of memory allocated, and all other matchers in Docker with 12GB of memory allocated. We used the MELT platform for all locally run systems except ALIN, for which we used the SEALS client, and Agent-OM, for which we followed the tool's instructions. Please note that the reported runtime for Agent-OM is based on running the tool with CPU rather than GPU.

As in earlier years, we slightly changed the way how precision and recall are computed, i.e., the results generated by the MELT and SEALS clients vary in some cases by 0.5% compared to the results presented below. In particular, we removed trivial correspondences in the oboInOwl namespace like:

http://...oboInOwl#Synonym = http://...oboInOwl#Synonym

as well as correspondences expressing relations different from equivalence. Using the Pellet reasoner we also checked whether the generated alignment is coherent, i.e., there are no unsatisfiable concepts when the ontologies are merged with the alignment.

Results

In the following, we analyze all participating systems that could generate an alignment. The listing comprises 14 entries. LogMap participated with different versions, namely LogMap, LogMapBio, LogMapKG and a lightweight version LogMapLite that uses only some core components as in previous years. In addition, LogMapBio has LLM integration resulting in the new participant, LogMapBioLLM. There are five systems, CHARM, DRAMA, LogMapBioLLM, Mosaic, and SECEA participating in the anatomy track this year for the first time. Agent-OM, LSMatch and LogMapLLM have participated in OAEI since last year. The rest of the systems have participated in OAEI for more than two years. From the systems participating this year, Matcha, Agent-OM, LSMatch, ALIN and LogMap (all versions except LogMapBioLLM) participated last year as well. LogMap is a constant participant since 2011 and ALIN joined in 2016. Matcha has been participating since 2022. For more details, we refer the reader to the papers presenting the systems. Thus, this year we have 9 different systems (not counting different versions) which generated an alignment.

For the tools that we ran locally, 6 systems were able to achieve the alignment task in less than 60 seconds (they require between 2 and 38 seconds to match the ontologies). These are LogMapLite, LogMapKG, LogMap, LSMatch, SECEA, and Matcha. In 2025 and 2024, there were 5 out of 11 and 3 out of 7 systems respectively which generated an alignment in this time frame. Similarly to the last 14 years, LogMapLite has the shortest run time (2 seconds). The table shows that there is no correlation between the required time for running and the quality of the generated alignment in any specific metric. This result has also been observed in previous OAEI campaigns.

The table also shows the results for F-measure, recall+ and the size of the alignments. Regarding F-measure, the top 3 ranked systems are DRAMA, Matcha, and LogMapBioLLM. Among these, DRAMA achieved the highest F-measure (0.951) which is higher than 0.941 of Matcha. This year, among the systems that participated last year, ALIN shows an increase in F-measure from 0.912 in 2025 to 0.931 in 2026. Regarding recall+, Matcha, LogMap, LogMapLite, LogMapKG, and LSMatch show similar results as earlier. The new participant DRAMA achieved the highest recall+ (0.902). ALIN's recall+ increases from 0.7 in 2025 to 0.733 in 2026. Regarding the number of correspondences, Matcha, LogMap, LogMapKG, LogMapLite, and LSMatch computed a similar number of correspondences as last year. Compared with last year's results, ALIN generated 15 fewer and Agent-OM generated 40 fewer correspondences.

This year 12 out of 14 systems achieved an F-measure higher than the baseline which is based on (normalized) string equivalence (StringEquiv in the table). Among these systems, DRAMA, LogMapBioLLM, CHARM, and Mosaic are new participants.

This year 6 systems produced coherent alignments which are LogMap, LogMapKG, LogMapBio, LogMapLLM, LogMapBioLLM, and DRAMA.

Conclusions

The number of participating systems varies between the years. In 2026, there are 3 and 7 participants more than the number of participants in 2025 and 2024 respectively. As noted earlier there are newly-joined systems as well as long-term participants.

This year, the new participant, DRAMA, sets the top result for the anatomy track with respect to the F-measure, followed by Matcha and LogMapBioLLM.
